# 🚀 UDP-CUSTOM INSTALLER

Script auto install UDP-Custom + System Manager + Menu VPS

---

## ⚡ FEATURES

- Auto install UDP-Custom binary
- Auto setup systemd service
- Auto timezone Asia/Colombo (GMT+5:30)
- Install menu manager (Add / Delete / List user)
- Auto download config.json
- Support exclude port/user parameter
- Auto restart service
- Clean & simple installer

---

## 📦 REQUIREMENTS

- Ubuntu / Debian VPS
- Root access
- Internet connection

---

## 🔧 INSTALLATION

Run command below on your VPS:

wget -O install.sh https://raw.githubusercontent.com/mandiriwe1/udp-custom/main/install.sh
bash install.sh
